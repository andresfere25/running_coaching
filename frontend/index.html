Glosario

Definiciones de los términos que aparecen en el dashboard. Sin jerga innecesaria.

Entrenamiento y carga
CTL Carga crónica · Fitness

Promedio ponderado de los últimos 42 días de entrenamiento (EWMA). Representa tu base de fitness acumulada.

En la práctica: CTL alto = llevas tiempo entrenando consistentemente. Un CTL en ascenso sostenido indica buena respuesta al entrenamiento — el valor absoluto varía según cada atleta.

ATL Carga aguda · Fatiga reciente

Promedio ponderado de los últimos 7 días. Refleja la fatiga acumulada en la semana actual.

En la práctica: ATL alto después de una semana fuerte es normal. ATL persistentemente por encima de CTL → riesgo de sobreentrenamiento.

TSB Balance Training Stress · Forma del día

TSB = CTL − ATL. Indica si estás fresco o fatigado en este momento.

TSB > +10 → fresco (bueno para una carrera). TSB 0–10 → en forma. TSB negativo → cargado. TSB muy negativo → señal de fatiga acumulada. Estos rangos son orientativos — interprétalos junto con cómo te sientes.

ACWR Acute:Chronic Workload Ratio · Ratio de carga

ACWR = ATL ÷ CTL. Compara lo que hiciste esta semana con lo que tu cuerpo está habituado a hacer.

0.8–1.3 → zona óptima (carga productiva). > 1.3 → zona de precaución. > 1.5 → precaución alta — la evidencia en corredores individuales es mixta, úsalo como señal, no como diagnóstico. < 0.8 → subentrenamiento.

Readiness Puntaje de disposición · /100

Score compuesto: TSB (40%) + ACWR (35%) + check-in subjetivo (25%). Resume en un número qué tan listo estás para entrenar hoy.

Es una métrica heurística — útil como referencia, no como diagnóstico médico. Valores: ≥75 óptimo, 55–74 bueno, 40–54 precaución, <40 recuperar.

Sesión clave

La sesión de running con mayor distancia de la semana. Es la más importante para el desarrollo de la base aeróbica — el resto de las sesiones giran alrededor de su recuperación.

Predicción de rendimiento
PR fuente

El mejor tiempo personal (Personal Record) que se usó como base para calcular la predicción. Si tienes PR de 21K y pides predicción para 42K, el PR fuente es 21K.

El sistema elige automáticamente el PR más cercano a la distancia objetivo.

Segmento

Clasificación del rendimiento del atleta: elite (<2:45h en 42K), sub3h, 3to4h, 4hplus. El modelo usa exponentes y márgenes de error calibrados por segmento.

Se calcula desde el PR declarado, no desde la meta. Afecta el margen de error del rango de ritmo.

Confianza ALTA / MEDIA / MEDIA-BAJA / BAJA

Qué tan confiable es la predicción según la distancia entre el PR fuente y la distancia objetivo.

ALTA = mismo PR. MEDIA = 1 distancia adyacente (ej. 21K→42K). MEDIA-BAJA = 2 distancias. BAJA = 3 distancias (ej. 5K→42K).

Corrección demográfica

Ajuste basado en edad y género aplicado sobre la predicción base de Riegel. Usa datos de 429.000 maratonistas reales para corregir el sesgo por grupo demográfico.

Ejemplo: un atleta de 55 años puede tener una corrección de +3–5 min en 42K versus un atleta de 35 con el mismo PR de 21K.

Capas activas

El sistema de predicción tiene 4 capas. Las que aparecen en la predicción son las que pudieron aplicarse con los datos disponibles.

Capa0 = Riegel base. Capa1 = prior demográfico. Capa2 = corrección residual por edad×género. Capa3 = corrección por carga CTL (reservada).

Extrapolación descendente

Cuando predices una distancia más corta que tu PR fuente (ej. predices 5K usando PR de 21K), la predicción es menos confiable porque los atletas no siempre tienen el mismo perfil aeróbico y de velocidad.

El margen de error se amplía automáticamente para reflejar esta mayor incertidumbre.

Plan y coach
Semáforo

Estado semanal calculado desde el último check-in del atleta: dolor, fatiga, sensación general y sueño. Determina el tipo de semana del plan.

VERDE = óptimo → semana de progreso. AMARILLO = precaución → semana conservadora. ROJO = reducir carga → semana de descarga. SIN CHECK-IN = sin datos recientes.

Tipo de semana PROGRESO / CONSERVADORA / DESCARGA

Define el volumen de la semana. PROGRESO: ligero aumento de carga sobre la semana anterior. CONSERVADORA: volumen moderado, sin incremento. DESCARGA: semana de recuperación activa, carga reducida.

Weekly focus

El objetivo técnico o de entrenamiento principal de la semana. Puede ser automático (generado por el sistema) o editorial (definido por el coach).

Cuando aparece el badge Coach significa que el coach lo definió manualmente.

Weekly objective

El objetivo concreto y medible de la semana en lenguaje simple: qué lograr, cuántos km totales, a qué ritmo. Siempre viene del coach.

Session notes

Indicaciones específicas del coach para una sesión concreta del día. Aparecen debajo de cada sesión en el Plan cuando el coach las ha agregado.

Ejemplo: "Inicia los primeros 10 min sin mirar el reloj" o "Si sientes pesadez en piernas, reduce 30 seg/km el ritmo objetivo."

Override del coach ✏ Coach ajustó

Ajuste manual del coach sobre el plan automático: km o ritmo diferente al sugerido por el sistema. El plan base sigue visible — el override aparece como contexto adicional.

El sistema genera el plan; el coach tiene la última palabra.

Alerts y restrictions

Alerts ⚠: advertencias del coach que piden atención o monitoreo. Restrictions 🚫: indicaciones que el atleta no debe ignorar esta semana (lesiones, fatiga acumulada, indicaciones médicas).

CTL, ATL, TSB y ACWR son métricas de carga derivadas de los datos de Strava. La predicción usa el modelo de Riegel calibrado con datos de Boston Marathon 2015–2018 (~100.000 corredores). Ninguna métrica de este dashboard reemplaza el criterio médico o de un entrenador calificado.
